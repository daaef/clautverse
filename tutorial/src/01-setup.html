In this chapter you install the tools and create an empty Nuxt 4 project. By the end you will see Nuxt's welcome page in your browser.

A terminal is a window where you type instructions instead of clicking. On a Mac open "Terminal"; on Windows open "PowerShell" (or use WSL). Every line in a grey command box below is something you type there, then press Enter.

The project's package.json declares "engines": {"node": ""}. That means "this project is built and tested on Node 24 or newer". Nuxt itself documents a lower minimum, but follow the project's number so everything in this guide behaves the same for you.

Install Node from nodejs.org (pick the current or LTS version that is 24 or higher) and Docker from docker.com. Then install pnpm:

npm install -g pnpm

Open Docker Desktop once so it is running in the background. You will need it in chapter 4.

Create the Nuxt 4 project

Nuxt's official command asks a few questions and then downloads a starter. This is the command from the Nuxt 4 installation page:

npm create nuxt@latest clautverse

Answer the questions like this:

  • Template: minimal. It is the emptiest starting point.
  • Package manager: pnpm.
  • Modules: choose none. Do not add Docus, Nuxt UI or anything else. We add exactly what we need by hand, so you understand every piece.
  • Git: yes, initialise a repository.

Prefer no questions? Use the flagged form from Nuxt's docs: npm create nuxt@latest clautverse -- --template minimal --packageManager pnpm --no-modules. When this guide was prepared that command produced the exact project described below.

Now move into the folder and start the development server:

cd clautverse pnpm dev

Open http://localhost:3000. You should see the Nuxt welcome page. In the terminal you will see a line saying the server is listening on that address. Press Ctrl+C in the terminal to stop the server whenever you want.

What the starter gave you

The minimal Nuxt 4 starter contains these files (we checked by generating one):

app/app.vue the root of the web page (shows ) public/ files served as-is (favicon, robots.txt) nuxt.config.ts Nuxt settings package.json the project's name, scripts and libraries tsconfig.json TypeScript settings (points at generated files) .gitignore files git should not save README.md starter notes

Nuxt 4 uses an app/ folder for everything the browser runs (pages, components, composables). Server code lives in server/ at the project root, next to it. Nuxt 3 projects kept both at the root; this guide uses the Nuxt 4 layout. Nuxt also generates a hidden .nuxt/ folder with types; you never edit it, and .gitignore keeps it out of git.

The starter's package.json scripts are what you will use all the time:

  • pnpm dev: run the server with live reload while you work.
  • pnpm build / pnpm preview: make and test a production build.
