## Outcome

The API runs at `http://localhost:3000` against a local PostgreSQL database.

::guide-section{id="local-setup-steps" title="Start the database and the API" type="code" expected-result="GET /api/health returns {\"status\":\"ok\",\"db\":\"ok\"}" verification="curl -s http://localhost:3000/api/health"}
```bash [Terminal]
docker run -d --name clautverse-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=clautverse -p 5432:5432 postgres:17
cp .env.example .env   # then fill NUXT_BETTER_AUTH_SECRET and NUXT_CURSOR_SECRET
pnpm install
set -a; . ./.env; set +a
pnpm db:migrate && pnpm db:seed
pnpm dev
```
::

::guide-section{id="local-setup-env" title="Environment variables" type="explanation"}
`.env.example` lists every variable with empty values. Your real `.env` is never committed. Without `NUXT_RESEND_API_KEY`, verification and password-reset emails are printed in the terminal instead of sent, so you can click the link locally.
::

## Troubleshooting

- `ECONNREFUSED 127.0.0.1:5432`: the database container isn't running. Run `docker start clautverse-pg`.
- `NUXT_DATABASE_URL is not set`: you skipped `set -a; . ./.env; set +a` in this terminal.
