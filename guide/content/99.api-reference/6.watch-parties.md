## 8. Watch parties

> **Decision 12:** event listing + external link (Instagram Live, X Spaces, YouTube, Zoom…) + "I'm going" RSVP. Times stored UTC, displayed in viewer's local time. Hosted live feed / hangout = post-launch idea.

#### WP-01 `GET /api/watch-parties?status=upcoming\|past&communityId=&limit=&cursor=` — CONFIRMED

Status: :badge[implemented]{color="success"}
- **Proof:** `tests/e2e/watch-parties.test.ts`
- **Caller:** Public. **200:** `{ items: WatchParty[], nextCursor }`. `upcoming` (= `scheduled|live`) → `startsAt asc, id asc`; `past` (= `ended|cancelled`) → `startsAt desc, id desc`.
- **Tests:** cancelled appear in `past` with status; pagination stable.

#### WP-02 `GET /api/watch-parties/:id` — PROPOSED (missing; needed for "shareable links") · public share page payload. `NOT_FOUND` if missing/community vetoed.

Status: :badge[implemented]{color="success"}
- **Proof:** `tests/e2e/watch-parties.test.ts`

#### WP-03 `POST /api/watch-parties` — CONFIRMED

Status: :badge[implemented]{color="success"}
- **Proof:** `tests/e2e/watch-parties.test.ts`
- **Caller:** community owner (talent) or admin. **Body:** `{ communityId, title (≤120), description?, startsAt: ISO future, endsAt?: ISO > startsAt, timeZone: IANA (e.g. "Africa/Lagos"), link?: https URL }`. Optional `Idempotency-Key`.
- **201:** `WatchParty`. **Errors:** `VALIDATION_FAILED` (past start, bad tz, non-https link), `FORBIDDEN`, `NOT_FOUND`.
- **Tests:** fan → 403; invalid tz → 400; times stored UTC, `timeZone` echoed for display.

#### WP-04 `PATCH /api/watch-parties/:id` — CONFIRMED · host/owner/admin; same fields optional; not after `ended|cancelled` (`INVALID_STATE`).

Status: :badge[implemented]{color="success"}
- **Proof:** `tests/e2e/watch-parties.test.ts`

#### WP-05 `POST /api/watch-parties/:id/cancel` — CONFIRMED · `200 WatchParty{status:"cancelled"}`; repeat 200; RSVP'd users notified.

Status: :badge[implemented]{color="success"}
- **Proof:** `tests/e2e/watch-parties.test.ts`

#### ~~WP-06 `POST /api/watch-parties/:id/notify`~~ — **Removed**: notifications are automatic (decision 13). On create → members with alerts on; reminder ~1 h before start (PROPOSED) → users who RSVP'd, sent by the scheduled job OPS-02.

#### WP-07 `PUT /api/watch-parties/:id/rsvp` · WP-08 `DELETE /api/watch-parties/:id/rsvp` — CONFIRMED (new; decision 12)

Status: :badge[implemented]{color="success"} :badge[implemented]{color="success"}
- **Proof:** `tests/e2e/watch-parties.test.ts`
- **Caller:** signed-in, onboarded user. Idempotent: PUT → `200 { going: true, rsvpCount }`; DELETE → `200 { going: false, rsvpCount }`. Not on `ended|cancelled` → `INVALID_STATE`. Unique `(partyId, userId)`. Talent sees `rsvpCount` (names list PROPOSED: owner/admin only via `GET /api/watch-parties/:id/rsvps`).

## 9. Notifications
