# Clautverse Implementation Guide

This guide explains how the Clautverse backend is built. Nuxt/Nitro is the real implementation. Short notes map each concept to React/Next.js.

Every important section has two buttons:

- **Question** builds a prompt you can paste into any AI tool to ask about that section.
- **Report** builds a troubleshooting prompt when something doesn't work.

Nothing is sent anywhere. You review the prompt and copy it yourself.
